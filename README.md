# robox

An industrial-tech-styled task and workforce management platform for the Robox AI and Robotics Center, with two role-based experiences — an Admin view (financial management, task allocation, admin dashboard, task group details) for overseeing operations and assigning work, and a Worker view (worker dashboard, leaderboard) for workers to track their assigned tasks and performance.
